# 01 - Lab Setup

## Overview

This project aims to build a complete Windows Server lab environment for learning and demonstrating Windows Server administration, Active Directory deployment, and PowerShell automation.

The lab simulates a small enterprise infrastructure consisting of one Windows Server acting as the Domain Controller and two Windows 11 client connected to the domain.

Throughout this project, administrative tasks will be automated using PowerShell, and every deployment step will be documented.

# Project Objectives

The objectives of this lab are to:

- Deploy a Windows Server environment from scratch.
- Configure Active Directory Domain Services (AD DS).
- Configure Domain Name System (DNS).
- Join a Windows 11 client to the domain.
- Automate user and group management with PowerShell.
- Build a reusable administration lab for learning and portfolio purposes.
- Document each deployment phase following professional documentation practices.
